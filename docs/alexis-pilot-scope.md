# Alexis Pilot — Family Home

## Pilot scope
- Alexis bedroom and bathroom lighting, ceiling fan, bathroom fan, and window shade.
- Security: Alexis left window, right window, bathroom window, and glass door contact states; alarm Arm Home, Arm Away, and Disarm.
- Shared Areas: main Lutron lights in kitchen, living room, and dining room; no cabinet lights.
- Oliver's Room: selected bedtime controls.
- Pool & Spa: limited safe controls respecting PoolOS authority.
- Humidifier: deferred; current Meross Matter plug is connected directly to Apple Home.
- Speakers and TV: excluded.

## Security requirements
The repository is public. Never commit secrets, HA tokens, alarm codes, or private addresses. All user permissions and alarm actions must be enforced by an authenticated backend. This document is a scope definition, not a deployed controller.
